# 🎬 MovieMood — Web Application UI/UX Design

Репозиторій для лабораторних та практичних робіт з дисципліни **«Розробка веб-застосунків»**.

---

## 📌 Про проєкт
**MovieMood** — це інтерактивний веб-сервіс для розумного підбору фільмів та серіалів на основі поточного настрою користувача, доступного часу, епохи та стрімінгових платформ. Проєкт спроєктовано з урахуванням подальшої розробки SPA-додатка на фреймворку **React**.

---

## 📂 Вміст репозиторію

У цьому репозиторії розміщено звіти та графічні матеріали за виконаними роботами:

* **`Звіт1`** — Звіт до Лабораторної роботи №1 (*Розробка та представлення ідеї проєкту веб-додатку*).
* **`Звіт2`** — Звіт до Лабораторної роботи №2 (*Представлення дизайну веб-додатку*).

> 💡 **Примітка:** Усі необхідні скріншоти, графічні макети, схеми та деталізовані фотографії інтерфейсу вже інтегровані безпосередньо всередину документів **`Звіт1`** та **`Звіт2`**.
