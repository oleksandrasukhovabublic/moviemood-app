# 🎬 MovieMood

**MovieMood** — це сучасний вебсервіс для персоналізованого підбору фільмів на основі поточного емоційного стану користувача, доступного часу для перегляду, жанрових уподобань, епохи та стрімінгових платформ.

### 🌟 Основна концепція та функціонал

Проєкт створено для розв'язання проблеми довгого пошуку фільму на вечір. Завдяки інтуїтивному UI/UX дизайну користувач може за кілька кліків знайти ідеальне кіно під свій настрій.

#### **Структура інтерфейсу:**

1. **Головна сторінка (HomePage / Discover):**
   * **Блок вибору настрою (Mood):** Інтерактивні картки з візуальними іконками (*Happy*, *Thrilling*, *Cozy* тощо).
   * **Панель швидких фільтрів:** Тривалість (`< 90 min`, `90–120 min`, `2h+`), епоха та стрімінгові сервіси (Netflix, Megogo, Sweet.tv).
   * **Головна кнопка дії (CTA):** «Find My Movie» для запуску підбору.

2. **Сторінка детальної інформації про фільм (MovieDetailsPage):**
   * Постер, банер, рейтинг, рік випуску, хронометраж та режисер.
   * Теги жанрів та настрою, синопсис сюжету, оцінки та акторський склад.
   * Перегляд офіційного трейлера та прямі посилання на стрімінги.
   * Кнопки збереження в «Обране», «Watchlist» та персональні колекції.

3. **Сторінка каталогу та пошуку (CatalogPage):**
   * Розширена фільтрація за настроєм, жанрами, роком та рейтингом.
   * Сортування за популярністю, рейтингом та датою виходу.

4. **Сторінка профілю користувача (ProfilePage):**
   * Особистий кабінет із статистикою та аватаркою.
   * Вкладки з улюбленими фільмами, списком перегляду та власноствореними добірками.

5. **Модальні вікна (Modals):**
   * Форма авторизації (Вхід / Реєстрація) з підтримкою Google та Apple.
   * Створення та редагування власних тематичних колекцій.
   * Перегляд трейлерів у вбудованому плеєрі.

### 🎨 Дизайн та UX

* **Dark UI:** Сучасна темна кольорова гама з яскравими неоновими та градієнтними акцентами (фіолетово-блакитні відтінки).
* **Мультимовність:** Повна підтримка перемикання інтерфейсу між українською та англійською мовами (UA/EN).
* **Адаптивність:** Зручна навігація та плавні анімації для будь-яких пристроїв.
