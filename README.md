# 🎬 MovieMood

**MovieMood** — це сучасний концепт вебсервісу для персоналізованого підбору фільмів на основі поточного емоційного стану користувача, тривалості перегляду, жанрових уподобань, епохи та стрімінгових платформ.

## 🌟 Структура інтерфейсу та екрани (Figma)

У дизайн-макеті реалізовано 5 основних екранів та модальні вікна:

1. **Головна сторінка (HomePage / Discover)**:
   - Інтерактивний блок вибору настрою (Mood) із візуальними іконками (Happy, Thrilling, Cozy тощо).
   - Панель швидких фільтрів за тривалістю, епохою та стрімінговими сервісами (Netflix, Megogo, Sweet.tv).
   - Головна кнопка дії (CTA) «Find My Movie».

2. **Сторінка детальної інформації про фільм (MovieDetailsPage)**:
   - Блок з постером, банером, рейтингом, роком випуску, хронометражем та режисером.
   - Теги жанрів, синопсис сюжету, оцінки та акторський склад.
   - Кнопки збереження в «Обране» та «Watchlist», а також прямі посилання на стрімінги.

3. **Сторінка каталогу та пошуку (CatalogPage)**:
   - Розширена фільтрація та сортування за популярністю, рейтингом і датою виходу.

4. **Сторінка профілю користувача (ProfilePage)**:
   - Особистий кабінет зі статистикою, аватаром та вкладками улюблених фільмів, запланованого й власних добірок.

5. **Модальні вікна (Modals)**:
   - Форми автентифікації (Вхід / Реєстрація) з підтримкою Google та GitHub.
   - Вікна для створення та редагування колекцій і перегляду трейлерів.

## 🎨 Дизайн та UX
- **Dark UI**: Сучасна темна кольорова гама з яскравими неоновими та градієнтними акцентами (фіолетово-чорні відтінки).
- **Мультимовність**: Проєктування інтерфейсу з урахуванням перемикання мов (UA/EN).
- **Адаптивність**: Продумана навігація для різних типів пристроїв.
